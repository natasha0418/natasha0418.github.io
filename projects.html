Phaser Pedal Design
April 2024
Phasers are widely used in audio processing to create swirling, spatial effects by modulating the phase of an audio signal. This pedal capitalizes on the properties of all-pass filters, which introduce phase shifts without affecting amplitude, to generate rich and evolving sonic textures. The circuit, based on a design from barbarach.com, was simulated on Tina TI, with constraints set based on available components. Hardware implementation involved estimating and tuning component values through testing. The system was built in modular stages to simplify debugging and testing. Audio signals were interfaced through a Behringer audio interface connected to a DAW for real-time sound processing.
Tools: TinaTI, KiCad

Hardware-Based Implementation of Heap Sort Algorithm
April 2025
Designed and implemented a hardware-based Heap Sort algorithm using a datapath and FSM controller architecture in Verilog. The design separates datapath and controller logic for modularity and ease of verification. The Heap Sort algorithm was divided into Heapify, Build-heap, and Extract-max operations. A high-level synthesis was performed using Bambu, followed by RTL verification with Icarus and Yosys.
Tools: Yosys, Bambu, Icarus
